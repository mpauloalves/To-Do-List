# Lista de Tarefas

Este é um simples aplicativo de Lista de Tarefas desenvolvido em HTML, CSS e JavaScript. O objetivo deste projeto é demonstrar como criar, armazenar e manipular tarefas utilizando o armazenamento local do navegador (LocalStorage).

## Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Armazenar tarefas no LocalStorage para persistência de dados

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

## Como Utilizar

1. Clone este repositório para sua máquina local:
    ```bash
    git clone https://github.com/mpauloalves/To-Do-List.git
    ```

2. Navegue até o diretório do projeto:
    ```bash
    cd To-Do-List
    ```

3. Abra o arquivo `index.html` em seu navegador preferido.
